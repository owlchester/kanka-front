# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add multilingual support (French, German, Spanish, PT-BR) to the kanka.io Nuxt 4 static marketing site, with AI-powered auto-translation on every English content change.

**Architecture:** `@nuxtjs/i18n` v9 handles routing (`prefix_except_default` strategy keeps English at `/features`, others at `/fr/features`), generates hreflang tags, and detects browser locale for the suggestion banner. All hardcoded Vue template strings are extracted to `locales/en.json`. `@nuxt/content` files move to `content/{locale}/` subdirectories. A GitHub Action calls Claude Haiku to retranslate changed files and commits back to main.

**Tech Stack:** Nuxt 4, `@nuxtjs/i18n` v9, `@nuxtjs/sitemap`, `@nuxt/content` v3, Claude Haiku 4.5 (Anthropic API), GitHub Actions

---

## File Map

**New files:**
- `locales/en.json` — all English UI strings
- `locales/fr.json`, `locales/de.json`, `locales/es.json`, `locales/pt-BR.json` — translated strings (populated by automation)
- `locales/manifest.json` — tracks last translation timestamp per file per locale
- `components/LocaleBanner.vue` — dismissable language suggestion banner
- `scripts/translate.mjs` — calls Claude API, writes translated locale/content files
- `.github/workflows/translate.yml` — triggers translate.mjs on push

**Moved:**
- `content/{faq,learn,pricing,team,use-cases,worldbuilding-guides}/` → `content/en/{faq,learn,pricing,team,use-cases,worldbuilding-guides}/`
- Copies created at `content/{fr,de,es,pt-BR}/` as English placeholders

**Modified:**
- `nuxt.config.ts` — add i18n + sitemap modules, remove old `/fr/**` → `/gone` redirects, update prerender routes
- `content.config.ts` — update all collection sources to `*/path/*.ext` wildcard pattern
- `composables/useSeo.ts` — add `og:locale` meta
- `app.vue` — dynamic `:lang`, remove manual hreflang link, add `<LocaleBanner>`
- `components/base/Nav.vue` — `$t()` + `localePath()`
- `components/base/Footer.vue` — `$t()` + `localePath()`
- Every translatable page in `pages/` — `$t()` for strings, `localePath()` for links
- `pages/use-cases/[slug].vue`, `pages/worldbuilding-guides/[slug].vue`, `pages/learn/[slug].vue` — locale-aware `queryCollection` paths

```ts
export function useLocaleData() {
  const { locale } = useI18n()

  function homeFaqCollection() {
    if (locale.value === 'fr') return 'homeFaqFr' as const
    if (locale.value === 'de') return 'homeFaqDe' as const
    if (locale.value === 'es') return 'homeFaqEs' as const
    if (locale.value === 'pt-BR') return 'homeFaqPtBR' as const
```

## Task 8: Update `useSeo.ts` with `og:locale`

- [ ] **Add `og:locale` and locale-aware canonical to the `useSeo` composable**

Open `composables/useSeo.ts`. Add locale mapping and fix canonical + ogUrl to use the actual route path (so `/fr/features` canonicals to `https://kanka.io/fr/features`, not the English path):

```ts
// add at top of file
const OG_LOCALE_MAP: Record<string, string> = {
  'en': 'en_US',
  'fr': 'fr_FR',
  'de': 'de_DE',
  'es': 'es_ES',
  'pt-BR': 'pt_BR',
}

export function useSeo({ title, description, path, ogTitle, ogDescription, schemas = [], noindex = false }: SeoOptions) {
  const { locale } = useI18n()          // ADD
  const route = useRoute()              // ADD
  const url = `${BASE_URL}${route.path}` // CHANGED: uses actual locale route path, not the English `path` param
  const resolvedOgTitle = ogTitle ?? title
  const resolvedOgDescription = ogDescription ?? description

  const meta: { name: string; content: string }[] = [{ name: 'description', content: description }]
  if (noindex) {
    meta.push({ name: 'robots', content: 'noindex,follow' })
  }

  useHead({
    title,
    meta,
    link: [{ rel: 'canonical', href: url }],
    script: schemas.map(schema => ({
      type: 'application/ld+json',
      innerHTML: JSON.stringify(schema),
    })),
  })

  useSeoMeta({
    ogTitle: resolvedOgTitle,
    ogDescription: resolvedOgDescription,
    ogUrl: url,
    ogLocale: OG_LOCALE_MAP[locale.value] ?? 'en_US',    // ADD
    twitterTitle: resolvedOgTitle,
    twitterDescription: resolvedOgDescription,
  })
}
```

## Task 17: Create `LocaleBanner` component

The banner appears at the top of the page when the visitor's browser language differs from the current page locale. It is dismissable and stores the dismissal in `sessionStorage`.

- [ ] **Create `components/LocaleBanner.vue`**

```vue
<template>
  <div
    v-if="visible"
    class="bg-blue text-white px-4 py-2 flex items-center justify-between gap-4 text-sm"
    role="alert"
  >
    <span>{{ bannerText }}</span>
    <div class="flex items-center gap-3">
      <a :href="localePath('/')" class="underline font-medium" @click="dismiss">
        {{ switchLabel }}
      </a>
      <button @click="dismiss" aria-label="Dismiss" class="opacity-70 hover:opacity-100">
        <i class="fa-regular fa-times" aria-hidden="true" />
      </button>
    </div>
  </div>
</template>

<script setup lang="ts">
const { locale, locales, availableLocales } = useI18n()
const localePath = useLocalePath()

const BANNER_TEXT: Record<string, { banner: string; switch: string }> = {
  fr: { banner: 'Ce site est disponible en français.', switch: 'Voir en français' },
  de: { banner: 'Diese Seite ist auf Deutsch verfügbar.', switch: 'Auf Deutsch ansehen' },
  es: { banner: 'Este sitio está disponible en español.', switch: 'Ver en español' },
  'pt-BR': { banner: 'Este site está disponível em português.', switch: 'Ver em português' },
}

const visible = ref(false)
const suggestedLocale = ref<string | null>(null)

onMounted(() => {
  if (sessionStorage.getItem('locale-banner-dismissed')) return

  const browserLang = navigator.language // e.g. "fr-FR", "de", "pt-BR"
  const browserCode = browserLang.toLowerCase()

  const match = availableLocales.find((code) => {
    if (code === locale.value) return false
    return browserCode.startsWith(code.toLowerCase()) || code.toLowerCase().startsWith(browserCode.split('-')[0])
  })

  if (match && BANNER_TEXT[match]) {
    suggestedLocale.value = match
    visible.value = true
  }
})

const bannerText = computed(() =>
  suggestedLocale.value ? BANNER_TEXT[suggestedLocale.value]?.banner ?? '' : ''
)
const switchLabel = computed(() =>
  suggestedLocale.value ? BANNER_TEXT[suggestedLocale.value]?.switch ?? '' : ''
)

function dismiss() {
  sessionStorage.setItem('locale-banner-dismissed', '1')
  visible.value = false
}
</script>
```

```yaml
name: Auto-translate

on:
  push:
    branches: [main]
    paths:
      - 'locales/en.json'
      - 'content/en/**'

jobs:
  translate:
    runs-on: ubuntu-latest
    permissions:
      contents: write

    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 2  # need previous commit to detect changes

      - uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Detect changed English files
        id: changed
        run: |
          CHANGED=$(git diff --name-only HEAD~1 HEAD -- locales/en.json 'content/en/**' | tr '\n' ' ')
          echo "files=$CHANGED" >> $GITHUB_OUTPUT

      - name: Translate changed files
        if: steps.changed.outputs.files != ''
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: node scripts/translate.mjs ${{ steps.changed.outputs.files }}

      - name: Commit translations
        if: steps.changed.outputs.files != ''
        run: |
          git config user.name "kanka-translate-bot"
          git config user.email "bot@kanka.io"
          git add locales/ content/fr/ content/de/ content/es/ content/pt-BR/
          git diff --staged --quiet || git commit -m "[bot] translate: update translations for changed files"
          git push
```
